Two versions of TapLink

Choose a screen to compare the installed apps. Both use simulated Hong Kong dollars. Each installation keeps its own cards, transactions and sample data.

Inside the apps

Which version would we present?

Use Astra for a short live demonstration. Start with the sample coffee QR, rotate the review, confirm the payment and find the debit in Activity. Deny location and choose Wan Chai to show an independently useful Android feature. The same QR images travel with the demo package.

Main has the advantage for an engineering walkthrough. Its Room schema, repository contract, WorkManager integration and more extensive verification record make it easier to explain several design and lifecycle decisions. Its full-screen receipt is especially clear when discussing automatic reload.
