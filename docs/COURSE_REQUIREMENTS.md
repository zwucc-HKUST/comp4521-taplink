# Course delivery requirements

Verified in the signed-in HKUST Canvas course on 22 November 2026 (Hong Kong time).

- Deadline: **30 November 2026, 23:59**.
- Each group submits one final report and one project program archive.
- Final report: Word or PDF, at most **5,000 words**. Canvas supplies a cover-page template. Naming example: `COMP4521 Group 1 - Final Report.pdf`; replace the group number with the actual assigned number.
- Program: complete source code in ZIP. Naming example: `COMP4521 Group 1 - Program.zip`.
- Presentation is a separate video submission, limited to **20 minutes** in the project specification.
- Generative AI may assist the project in any manner, but its use must receive proper credit. The final-submission page explicitly requires stating AI use in both the program and report.
- The project specification assigns 70% of the course-project score to the final project/report, 20% to presentation and 10% to proposal.
- Final-project rubric: results 60%, report clarity and English 30%, software engineering 10%. The strongest band includes code quality, improvements to the design, and a thorough executed test plan with expected outcomes.
